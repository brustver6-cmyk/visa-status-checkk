# Visa Status Check (RU/EN) — Railway-ready

Небольшой сайт для проверки **кода/номера заявки** + админ-панель для управления статусами.

## Что внутри
- Публичный сайт: **EN/RU** переключение языка (всё переводится)
- Страница проверки статуса (ввод кода, результат)
- Админ-панель (интерфейс на русском)
  - Автогенерация кода заявки
  - Статусы выбираются **на английском** (In Processing / Approved / Granted / Refused / Cancelled / Additional Documents Required)
  - Тексты сообщений можно хранить в **RU и EN**
  - Кнопка **Auto-translate** (если включить переводчик через ENV)

## Важный момент про «авто-перевод текста»
Без внешнего сервиса (API) *невозможно* качественно переводить любой произвольный текст автоматически.
Поэтому тут так:
- Статусы переводятся встроенно (EN↔RU) всегда.
- Произвольный текст сообщения — либо вводишь RU и EN вручную, либо включаешь переводчик через `TRANSLATE_ENDPOINT`.

## Быстрый старт локально
1) Установи зависимости:
```bash
npm i
```
2) Создай `.env` (пример ниже)  
3) Запуск:
```bash
npm start
```
Открой: http://localhost:3000

## ENV переменные
Создай файл `.env` рядом с `server.js`:

```bash
PORT=3000
SESSION_SECRET=change_me_please

# Первичный админ (создаётся автоматически при первом запуске)
ADMIN_USER=admin
ADMIN_PASS=admin12345

# (опционально) авто-перевод (LibreTranslate-совместимый endpoint)
TRANSLATE_ENDPOINT=https://libretranslate.example.com/translate
TRANSLATE_API_KEY=
```

## Деплой на Railway через GitHub
1) Залей репозиторий на GitHub  
2) Railway → New Project → Deploy from GitHub  
3) Добавь ENV (как выше) в Railway  
4) Готово

> База данных: файл `data.sqlite` создаётся автоматически в корне проекта.  
> На Railway файловая система может быть **не постоянной**. Для продакшна лучше Postgres.  
> Если надо — переделаю на Postgres.
